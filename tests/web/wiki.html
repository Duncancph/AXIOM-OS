An operating system (OS) is system software that manages computer hardware and software resources, and provides common services for computer programs.[1]

Time-sharing operating systems schedule tasks for efficient use of the system and may also include accounting software for cost allocation of processor time, mass storage, peripherals, and other resources.[2]
